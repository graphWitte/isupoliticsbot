# Деплой

Пока проект живёт на твоём компьютере: бот работает, только пока включён
`npm run dev:all`, а приложение в Telegram не открыть совсем — Telegram не
пускает `localhost`.

Два варианта. Оба рабочие, разница в цене и в том, сколько кода менять.

## Вариант A — бесплатно: Vercel + Neon

**Плюсы:** 0 ₽, работает круглосуточно, компьютер не нужен.
**Минусы:** бота надо перевести на вебхуки (сделаю я), и часть российских
провайдеров режет IP Vercel — по жалобам на их форуме не открываются
собственные домены, адреса `*.vercel.app` работают. Если перекроют и их,
админка откроется только через VPN. **Бот при этом не пострадает:** к нему
обращаются серверы Telegram, а не телефоны отдела.

### Что сделать тебе (≈5 минут)

Аккаунты за тебя завести я не могу — это делаешь ты сам.

1. **Neon** — [neon.com](https://neon.com), войти через GitHub, создать проект
   (регион поближе, например Frankfurt). Скопировать строку подключения
   (`Connection string`, с галочкой **Pooled connection**).
2. **Vercel** — [vercel.com](https://vercel.com), войти через GitHub,
   импортировать репозиторий `isupoliticsbot`.
3. Сказать мне, что готово, и прислать **только адрес**, который выдал Vercel
   (вида `isupoliticsbot.vercel.app`). Строку подключения к базе и токен бота
   **в чат не присылай** — впишешь их сам в Vercel → Settings → Environment
   Variables, по списку, который я дам.

### Что сделаю я

- Переведу бота с опроса на вебхуки (на Vercel нет постоянно живущего процесса).
- Сделаю отдельный адрес для проверки протухших квестов и подключу бесплатный
  внешний планировщик: встроенный в Vercel на бесплатном тарифе запускается
  раз в сутки, а нам нужна минута.
- Накачу схему на Neon, проверю вход, приложение и бота на живом адресе.

## Вариант B — свой сервер (VPS или сервер вуза)

**Плюсы:** стабильно открывается из России, код менять почти не надо —
`docker compose up` и всё. **Минусы:** нужны деньги или договорённость с вузом.
У Timeweb Cloud сервер с 2 ГБ памяти — около 900 ₽/мес, есть и дешевле.

Если пойдём этим путём, я подготовлю `Dockerfile` и `docker-compose.prod.yml`,
и разворачивание будет в одну команду.

## После деплоя (оба варианта)

1. В `.env` на сервере: `APP_URL` = публичный https-адрес.
2. **@BotFather → `/setdomain`** → этот домен. Без этого не заработает кнопка
   «Войти через Telegram» (вход через `/admin` будет работать всегда).
3. **Перевыпустить токен бота** (`/revoke` у @BotFather) — текущий засветился в
   переписке. Новый вписать в переменные окружения на сервере.
4. Проверить: кнопка «Квесты» слева от поля ввода открывает приложение.

## Переменные окружения

| Переменная | Что это |
|---|---|
| `DATABASE_URL` | строка подключения к базе |
| `BOT_TOKEN` | токен от @BotFather |
| `BOOTSTRAP_ADMIN_IDS` | `964746097` — всегда ADMIN |
| `APP_URL` | публичный https-адрес, без слеша на конце |
| `APP_TZ` | `Asia/Irkutsk` (UTC+8) |

Чат отдела в переменных не задаётся — он привязывается командой `/bind`.
