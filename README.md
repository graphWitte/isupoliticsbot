# Квест-борд медиа-отдела

Задачи медиа-отдела как квесты: руководство ставит — отдел разбирает в
Telegram — куратор принимает.

- **Бот** (grammY) — карточки квестов в чате отдела, «Беру» / «Сдать», приёмка кнопками
- **Админка** (Next.js) — доска, создание квестов, приёмка, рейтинг, роли

Что уже есть и что дальше — в [ROADMAP.md](ROADMAP.md).

## Быстрый старт

Нужны Node 22+ и Docker Desktop.

```bash
cp .env.example .env     # впиши BOT_TOKEN и свой ID в BOOTSTRAP_ADMIN_IDS
npm install
npm run db:up            # Postgres в докере на :5433
npm run db:migrate       # схема в базу
npm run db:seed          # завести суперадминов из .env
npm run dev:all          # админка на :3000 + бот
```

Дальше всё настраивается из Telegram:

1. Напиши боту `/start`. Свой Telegram ID для `.env` — команда `/id`.
2. Добавь бота в чат отдела и отправь там `/bind` — туда будут падать квесты.
   Для теста можно отправить `/bind` прямо в личке с ботом.
3. `/admin` — одноразовая ссылка для входа в админку.

## Команды бота

| Команда | Кто | Что делает |
|---|---|---|
| `/board` | все | свободные квесты |
| `/my` | все | мои квесты в работе |
| `/me` | все | очки и место в рейтинге |
| `/new` | кураторы | черновик квеста: первая строка — заголовок, дальше бриф |
| `/admin` | кураторы | ссылка для входа в админку |
| `/bind` | кураторы | привязать чат (или тему), куда падают квесты |

## Разработка

```bash
npm run typecheck
npm test                 # гоняет гонку за «Беру» на настоящей базе
npm run db:studio        # посмотреть базу глазами
```

На Windows запущенные бот и `next dev` держат файл движка Prisma — перед
`npm run db:migrate` их нужно остановить, иначе `prisma generate` упадёт с EPERM.

## Структура

```
prisma/schema.prisma   модель данных
src/server/            бизнес-логика, общая для бота и админки
src/bot/               бот (grammY, отдельный процесс)
src/app/               админка (Next.js App Router)
src/components/        UI админки
src/lib/               env, время и пояс, подписи статусов
```
